Event Management API Portal

Welcome to the Event Management Backend API. Use the following endpoints to interact with authentication, events, analytics, registrations, profiles, feedback systems, and realtime observability infrastructure.

🔐 Authentication Routes

  • POST
    /api/auth/register
    Register a new user.
    Body: { name, email, password }
  • POST
    /api/auth/login
    Login user and return JWT token.

🎟 Event Routes

  • POST
    /api/event
    Create a new event.
  • GET
    /api/event
    Get all events.
  • GET
    /api/event/:id
    Get event details by ID.
  • PUT
    /api/event/:id
    Update event details.
  • DELETE
    /api/event/:id
    Delete an event.

📝 Registration Routes

  • POST
    /api/registration
    Register for an event.
  • DELETE
    /api/registration/:eventId
    Cancel event registration.
  • GET
    /api/registration/user
    Get registered events for user.

👤 Profile Routes

  • GET
    /api/profile
    Get user profile details.
  • PUT
    /api/profile
    Update user profile.
  • GET
    /api/profile/analysis
    Get AI-powered profile analysis.

💬 Feedback Routes

  • POST
    /api/feedback
    Submit platform feedback.
  • GET
    /api/feedback/analytics
    Get feedback analytics.

📊 Performance Routes

  • GET
    /api/performance
    Get realtime API observability stats.
🔒 All protected routes require:

Authorization: Bearer <token>
